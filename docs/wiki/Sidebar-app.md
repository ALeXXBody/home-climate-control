# Sidebar app

After setup, **Home Climate** appears in the HA sidebar.

| Tab | Purpose |
|---|---|
| **Home** | Outdoor, flow, demand, gas estimate, boiler pill |
| **Rooms** | Per-room cards: temp, Mode/Profile, Edit/Delete, insights (warm rate, dead-time, lead, pre-heat) |
| **Devices** | Select HCS board, live controls, firmware catalog + OTA |
| **Diagnostics** | Curve, CycleGuard, duty cycle, schedule, occupancy, setbacks, gas (mode / ΔT / hydronic kW) |

Header: boiler link status. Footer: integration version.

After updating HCC, hard-refresh (Ctrl+Shift+R) if the UI looks stale.
